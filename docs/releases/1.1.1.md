# 1.1.1 — 共通LCD処理の修正

機械語サンプルで共用するLCD書き込み処理に、BUSY解除の待機が欠けていました。実機で表示が乱れる原因となるこの不具合を修正しました。

対象は基礎サンプル5本、JR DINO、RELIC DIVEの全7本です。このタグのSDKで再ビルドしてください。

## 修正内容

- 各LCDコマンド・データの書き込み前に、コントローラーのBUSY解除を待つようにしました。
- JR DINOとRELIC DIVEは、画面転送の区切りでもキーを読み、短い押下を保持します。
- LCDがBUSYを返す条件で、共通処理の待機と分割転送を検証する回帰テストを追加しました。

## 検証

- Native: 58テスト成功。
- WASM: 15テスト成功。
- 共通LCD処理の12条件、および全7本の描画・入力検査に成功。
