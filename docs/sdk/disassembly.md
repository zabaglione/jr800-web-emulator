# HD6301逆アセンブル

ポータブルC++の逆アセンブル機能は、プロジェクト管理下のISAメタデータから1命令ずつデコードします。
Nativeツールとデバッガーが同じ命令表記とオペランド解釈を使うため、用途ごとのオペコード表は持ちません。

`disassemble_one`は、CPUプロファイル、16ビットの命令アドレス、残りのバイト列を受け取り、次のいずれかを返します。

- `decoded`：確認済みの完全な命令
- `unknown_opcode`：選択したプロファイルで未確認の1バイト
- `truncated_instruction`：必要なオペランドが不足した確認済みオペコード
- `end_of_input`：入力バイトなし

未知または途中で切れた命令は1バイトだけを消費し、`.byte $NN`と表示します。
呼び出し側はデータを失わずに次のバイトへ進めますが、構造化された状態によってデコードできなかった理由を区別できます。
別のCPUプロファイルの命令を推測して使うことはありません。

即値、direct、extended、relative、indexed、HD6301のimmediate-plus-memory形式は、`jr8as`と同じオペランド順を使います。
相対分岐先は命令直後のアドレスから計算し、16ビットで折り返します。
この機能は呼び出し側から渡された範囲だけを読み、バスアクセスやI/Oを起こしません。

デバッガーは最初にオペコード1バイトを読みます。
確認済み命令の残りが必要な場合だけ、メタデータで定めた追加バイトを読み直します。
命令末尾より先を調べないため、未知オペコードは読める1バイトだけで表示できます。
