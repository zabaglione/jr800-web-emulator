# JR8LDリンクスクリプトバージョン1

## 用途

リンクスクリプトは、JROのセクションを16ビットメモリー領域へ決定的に配置します。
標準拡張子は`.j8l`です。
汎用式、ワイルドカード、暗黙配置、overlay、既存ベンダーリンカーとの互換構文はありません。

## 構文

ファイルはUTF-8です。
空行を無視し、`;`から行末までをコメントとします。
空でない各行には、1個のコマンドと空白区切りのオペランドを書きます。

```text
target hd6301v1
entry entry
region ZP $0000 $0100
region CODE $0200 $1E00
region DATA $2000 $0100
place .text CODE
place .data DATA
place .bss ZP
```

コマンド名と領域名は大文字・小文字を区別します。
`target`は、全入力JROに記録されたCPUプロファイルと完全一致させます。
`entry`は、定義済みglobal addressシンボルを指定します。
数値は10進または`$`付き16進です。

`region name origin length`は、空でない半開アドレス範囲を宣言します。
領域は重複できず、`$10000`を越えてはいけません。
`place section region`は、完全一致するセクション名を宣言済み領域へ割り当てます。
空でない全入力セクションに、ちょうど1個の配置が必要です。

処理順はコマンドライン上のオブジェクト順、その中のJROセクション順です。
relocatableセクションは、指定アラインメントを満たす次のアドレスへ配置します。
fixedセクションは元のアドレスを保持し、アラインメント、領域、非重複の条件を満たす必要があります。
領域からはみ出したセクションを別領域へ自動移動しません。

## コマンド

```sh
jr8ld --script memory.j8l \
  -o app.j8a --debug app.j8d \
  --map app.map --symbols app.sym \
  main.jro lib.jro
```

オブジェクト引数の順序は配置結果に影響します。
同じバイト列の入力を同じ順序で指定すると、同じJR8APP、JR8DBG、map、symbolファイルを生成します。
