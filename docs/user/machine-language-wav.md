# JR-800機械語プログラムWAVの利用ガイド

## このWAVは何か

JR-800向けの機械語プログラムは、WAVファイルで配布されていることがあります。
このWAVはROMイメージではありません。
JR-800のRAM上に置かれた機械語プログラムを、BASICの`MSAVE`でカセットへ保存した音声です。

JR-800用エミュレーター間で共通の機械語ファイル形式が定着していないため、実機で読み込めるWAVが配布形式として使われています。
本プロジェクトのWeb UIは、WAVからロードアドレス、実行アドレス、機械語本体をブラウザー内で復元し、そのまま実行できます。
必要な場合は、同じ内容をプロジェクトのJR8APP形式である`.j8a`へ保存することもできます。

## 実機で動かす

必要なものは、JR-800実機、配布されたWAV、JR-800のカセット入力へ音声を再生できる機器です。
接続方法と再生レベルは、実機と再生機器の説明書に従ってください。

配布元から別の指定がない場合は、実機で次のコマンドを使います。

```text
MLOAD "",,R
```

WAVの再生開始とコマンド入力の順序は、配布元の説明に従ってください。
`R`は、WAVのヘッダーに記録された実行アドレスから続けて実行する指定です。

## Web UIで動かす

先に[README](../../README.md)の手順でWeb UIを起動し、自分で取得したJR8ROMを用意します。

1. `JR-800 hardware model`の`.J8R / .ROM`でROMを選び、`.rom`の場合は確認ダイアログで続行します。
2. `Boot BASIC experiment`を押します。
3. BASICの画面が安定するまで待ち、まだ実行中なら`Pause`を押します。
4. `RAM program .WAV / .J8A`で配布されたWAVを選びます。
5. `Load and run RAM program`を押します。

Web UIはWAVの信号開始、ヘッダー、データ、チェックサム、RAM範囲、実行アドレスを検証します。
変換できない場合は、未対応のWAV形式、信号未検出、同期失敗、データ途中終了、フレームエラー、チェックサム不一致、未対応ヘッダー、アドレス範囲などの理由を画面に表示します。
失敗したWAVを推測でRAMへ書き込むことはありません。

変換に成功すると、記録された範囲をJR-800のRAMへ読み込み、実行アドレスから自動的に実行します。
ROM、I/O、未構成の拡張RAMには書き込みません。
読込時にはBASIC起動後のCPUと周辺機器の状態を保ち、PCだけをWAVの実行アドレスへ移します。

この経路は、カセット入力の波形処理時間や再生時間をエミュレートしません。
実機の`MLOAD "",,R`が実行開始時に作るレジスター、スタック、周辺機器の正確な状態も、現時点では未確認です。

## `.j8a`として保存したい場合

Web UIで実行するだけなら、この変換作業は不要です。
変換結果を保存して繰り返し使う場合は、付属のコマンドラインツールを使用します。

### 1. 変換ツールを用意する

リポジトリのルートでNative Release版をビルドします。

```sh
cmake --preset native-release
cmake --build --preset native-release
```

### 2. WAVを非公開の場所へ保存する

元のZIP、WAV、復元した機械語、変換後の`.j8a`は、Gitへ追加しないでください。
このリポジトリ内へ置く場合は、Git管理外の`local-data/`を使えます。

```sh
mkdir -p local-data/programs
```

### 3. WAVを`.j8a`へ変換する

```sh
build/native-release/tools/jr8wav decode-native-program \
  path/to/program.wav \
  local-data/programs/program.j8a
```

変換器は、16-bit PCMのmonoまたはstereo WAVを読み、信号の開始位置、ヘッダー、データ、チェックサムを検証します。
stereoの場合は信号の強いチャンネルを選びます。
ヘッダーの解釈が一意に決まらない、RAM範囲外を指定している、実行アドレスがデータ範囲外にある、チェックサムが一致しない場合は変換しません。

実機で録音したWAVには、操作を始める前の無信号部分が含まれていても構いません。
変換器は、録音全体を複数回の保存操作として扱うのではなく、一つのWAVから開始信号に続くヘッダーとデータを探します。

現在確認している入力は48,000 Hz、16-bit PCMです。
異なるサンプルレート、圧縮WAV、他機種のWAV、BASICプログラムを`SAVE`したWAVには対応しません。

## 変換できない場合

- 入力が48,000 Hz、16-bit PCMのWAVか確認します。
- ZIPを直接指定せず、中のWAVを取り出して指定します。
- BASICを`SAVE`したWAVや他機種用WAVでないか確認します。
- 録音したWAVでは、音量不足やクリッピングがないか確認します。
- Web UIではZIPを展開してWAVを選び、コマンドラインではWAVを入力に指定します。

Web UIの画面または`jr8wav`の診断が、未対応形式、読み取れない波形、チェックサム不一致、アドレス範囲エラーのどれかを確認してください。
変換器が一意に解釈できないWAVを、推測で実行可能ファイルにはしません。
