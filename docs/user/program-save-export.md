# エミュレーターからJ8A・WAVへ保存する

エミュレーター内で`SAVE`または`MSAVE`を実行すると、保存した内容をJ8AとWAVの両方でダウンロードできます。
対応ROMは、読み込み機能と同じJR-HuBASIC 1.0／2.0です。

## 保存の手順

1. 自分のROMでBASICを起動し、保存したいプログラムを入力するか読み込みます。
2. エミュレーションを実行中にして、BASICから保存命令を入力します。
3. 保存が完了すると、画面の「データをファイルへ保存」にファイルが追加されます。
4. そのファイルの「J8Aをダウンロード」または「WAVをダウンロード」を押します。

| BASICでの入力例 | 保存する内容 | ダウンロード名 |
| --- | --- | --- |
| `SAVE "MyBasic"` | 現在のBASICプログラムを内部形式で保存 | `MyBasic.j8a`／`MyBasic.wav` |
| `SAVE "MyText",A` | 現在のBASICプログラムをASCII形式で保存 | `MyText.j8a`／`MyText.wav` |
| `MSAVE "MyCode",24576,24591,24580` | `$6000`〜`$600F`の16バイトと実行開始アドレス`$6004` | `MyCode.j8a`／`MyCode.wav` |

`MSAVE`の例は、あらかじめ指定範囲に機械語やデータを用意して使います。
通常のSAVE処理が動くため、長いプログラムは完了まで時間がかかります。
一時停止すると保存処理も止まるので、再開して完了を待ってください。
完了後は同じ項目から両方の形式を何度でもダウンロードできます。

## ファイル名と形式

ファイル名は、ROMが保存ヘッダーへ書いた名前から作ります。
大文字・小文字を保ち、カナは半角カナに変換します。
GRAPHなど通常のファイル名へ変換できない文字は`_XX`（元の文字コードの16進表記）にします。
ファイル名に使えない記号は`_`へ置き換え、空の名前は`PROGRAM`にします。
ファイル内部には、元のJR-800の名前をそのまま保持します。
同名ファイルを繰り返しダウンロードした場合の連番はブラウザーの設定に従います。

J8Aは現行のバージョン1です。BASICの内部形式／ASCII形式、機械語の区別を保持します。
WAVはJR-800の保存ブロックから生成する48 kHz・16ビットPCM・モノラル音声です。
両方とも、既存のプログラム読み込み欄からエミュレーターへ戻せます。
ASCII SAVEのJ8Aも、一般的なテキストファイルではなくJ8A形式です。

## 保存一覧の扱い

一覧には完了済みの保存を最大32件保持します。
上限に達したら必要なファイルをダウンロードし、「保存データの一覧を消去」を押してから保存命令を実行し直してください。
同名で再度SAVEしても以前の項目を上書きしません。

保存途中のリセットでは、不完全なデータを破棄し、完了済みの項目を残します。
保存中は一覧を消去できません。
別のROMの読み込み、ページの再読み込み、タブを閉じる操作では一覧が失われるため、その前にダウンロードしてください。
ファイルはブラウザー内で生成し、外部へ送信しません。

SAVEが保存するのはBASICプログラムです。変数や実行途中の状態を含むスナップショットではありません。
別領域に置いた機械語やデータが必要な場合は、その範囲をMSAVEでも保存してください。
機械語の出力は、既存のJ8A読み込みと同じ対応RAM範囲を対象とします。

## 検証済みの範囲と実機確認

両ROMについて、短いBASIC、複数ブロックになる長いBASIC、カナ・GRAPHを含むBASICを通常SAVEとASCII SAVEで出力しました。
J8AとWAVをエミュレーターへ再読込し、BASIC内部のプログラム全体が一致することを確認しています。
ブラウザー上でも両ROMのSAVE／ASCII SAVE／MSAVEから計12ファイルをダウンロードし、WAVから再変換したJ8Aが対になるダウンロードと一致しました。
検証条件と制限は[対応範囲](compatibility.md)を参照してください。

**BASIC内部形式で保存したプログラムは、ZOOM H2nの再生ボリューム`60`で実機読込に成功した実施例があります。**
H2nで再生できるよう、WAVを個別にステレオへ変換し、Lに元の音声、Rに無音を入れた条件です。
接続はH2nのLINE OUTからJR-800のモニター端子です。録音時は逆方向に、JR-800のマイク端子からH2nのLINE INへ接続し、ゲイン`6`を使っています。
接続・設定と確認範囲は[ZOOM H2nの実施例](compatibility.md)を参照してください。
ASCII SAVEとMSAVEの実機読込は未確認です。別のプログラムを実機へ戻す場合は、次の確認をしてください。

1. エミュレーターで短いプログラムをSAVEし、WAVをダウンロードします。
2. 実機で`LOAD "名前"`を実行して読込待ちにし、カセット入力へ接続したプレーヤーでWAVを再生します。機械語は`MLOAD "名前"`を使います。
3. BASICは`LIST`と`RUN`、機械語は保存範囲の内容で確認します。プレーヤー、音量、使用ROM版、成功／エラーを記録してください。

生成波形は既知のネイティブ形式と実測ビット周期に基づきますが、実機の入力回路、再生機器、音量の許容範囲はこの検査では確定していません。

## データだけをMSAVEした場合

`MSAVE "DATA",24576,24591,0`のように実行開始アドレスを保存範囲の外へ指定した場合も、J8AとWAVに元の値を保持します。J8Aはバージョン1.0です。
戻すときは「読み込む」を使います。「読み込んで実行する」は範囲外の実行開始アドレスを検出し、RAMとCPUを変更せずに拒否します。

開発者用デバッガーの「再起動（RAMを初期化）」は作業用RAMを消去しますが、完了した保存データの一覧は維持します。保存途中の内容は破棄します。
