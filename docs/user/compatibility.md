# 対応機能と確認済みの範囲

利用者が用意したJR-HuBASIC 1.0／2.0のROMを使うエミュレーターです。
ROM本体、実機録音、私用プログラムは配布物に含めません。
以下は確認した組合せでの結果であり、すべての機器・プログラムでの動作を保証するものではありません。

## BASICとキーボード

両ROMでBASICの起動と代表的なキー入力を確認しています。
JR-HuBASIC 2.0では「未対応I/Oで停止しない」を有効にしてください。
inufuto氏のゲーム群について動作確認の報告があります。
別途、22本を各500,000命令実行する検査で、CPUの異常停止がないことを確認しました。
ゲーム全体の動作と実機との完全一致を検証したという意味ではありません。

仮想キーボードはCAPS.L、SHIFT、CTRL、GRAPH、カナの状態を表示します。
GRAPHとカナの字形は、読み込んだROMのフォントデータから取得します。
実機の同時押しや電気的なキー走査には未確認の条件が残ります。

## 日時と再起動

「ブラウザーの現在日時でBASICを起動する」を有効にすると、2000〜2099年の日時・曜日・うるう年の状態を起動時に一度だけ設定します。
ROMの内容は書き換えません。常時の時刻同期は行わず、オプションを外すと元の起動時の値を使います。
`DATE$`による日付設定と曜日の設定は独立しています。
`WAKE`によるアラーム、電源制御、実行復帰は未対応です。

POWER OFF／ONは、状態を保持してエミュレーションを停止・再開します。
開発者用デバッガーの「再起動（RAMを初期化）」は作業用RAMと周辺機器を起動時の状態へ戻します。
ROMと完了済みの保存データ一覧は残りますが、未保存のプログラムは失われます。
これらはブラウザー側の操作であり、実機の電源回路やRESET端子の動作を再現するものではありません。

## BASIC・機械語の読み込みと保存

通常SAVE、ASCII SAVE、MSAVEをWAV／J8Aで扱います。J8Aの形式はバージョン1です。
短いBASIC、複数ブロックの長いBASIC、カナ・GRAPH入りBASICを通常SAVEとASCII SAVEで各2回録音した12本について、復元した内容の一致を確認しました。
両ROMでWAV／J8Aからの読込、LIST、RUNを確認しています。

エミュレーターから保存したJ8AとWAVは、再読込したプログラム内容が一致します。
データ用MSAVEでは実行開始アドレスが保存範囲外でも値を保持します。
その場合は「読み込む」で戻せますが、「読み込んで実行する」はRAMとCPUを変更せずにエラーを表示します。

読込は検証したカセットブロックをROMのLOAD処理へ渡します。
カセット入力の電圧や実時間の転送を再現するものではありません。
複数ファイルを続けて録音したテープ、MERGE、実行途中のスナップショット、BASICと別の機械語ファイルの一括読込は未対応です。

## ZOOM H2nによる実機読込の例

録音・再生に使用した接続と設定は次のとおりです。

| 操作 | 信号の向き | H2nの設定 | JR-800の命令 |
| --- | --- | --- | --- |
| JR-800から録音 | JR-800のマイク端子 → H2nのLINE IN | ゲイン`6` | `SAVE`、`MSAVE` |
| JR-800へ読み込み | H2nのLINE OUT → JR-800のモニター端子 | Volume `60` | `LOAD`、`MLOAD` |

BASIC内部形式で保存した147バイトのプログラムについて、次の条件で実機への読み込み成功が報告されています。

| 項目 | 実施条件 |
| --- | --- |
| 再生機器 | ZOOM H2n |
| 再生ボリューム | `60` |
| WAV | 48 kHz、16ビットPCM、ステレオ |
| Lチャンネル | エミュレーターが出力したモノラル音声 |
| Rチャンネル | 無音 |

H2nで再生するため、出力後にWAVをステレオへ変換した例です。
エミュレーターの標準出力はモノラルです。
実機でのLIST／RUNや全バイト比較、ASCII SAVE／MSAVEの書き戻し、他のプレーヤーや音量の許容範囲は、この実施例では確認していません。
再検証には[実機テスト手順](basic-program-physical-test.md)を利用してください。

## ブラウザー内の保存と公開配信

Chromeでブラウザーの終了・再起動後にROMのファイル名と起動設定が復元されることを確認しています。
復元時にはROMの内容を読まず、「BASICの起動」を押した時点で読み込みます。
別のROMへの変更、保存コピーの削除、保存領域が使えない場合の手動起動も検証しています。
ROM、WAV、プログラムを外部へ送信する処理はありません。

[GitHub Pagesの公開URL](https://zabaglione.github.io/jr800-web-emulator/)でも、両ROMの起動とブラウザー再起動後のファイル名復元・明示的な起動を確認しています。
配下URLでのWorker／WASMの読込や保存の例外処理は、市販ROMを使わない合成データでも検査しています。
自分のリポジトリで配信する場合は、[GitHub Pagesの設定手順](github-pages.md)を参照してください。
