# BASICプログラムWAVの利用ガイド

BASICも機械語と同じ`.wav / .j8a`のファイル選択から読み込めます。
対応するJR-HuBASIC 1.0または2.0のROMを、利用者自身で用意してください。

## 実機から保存する

通常の`SAVE "名前"`はBASIC内部形式で保存します。
ソースをテキストとして保存する場合は次のように指定します。

```text
SAVE "PROGRAM",A
```

カセット出力をWAVへ録音します。
機械語用の`MSAVE`でBASICの管理領域を推測して取り出す必要はありません。
現在の復号器は48 kHz、16ビット整数PCMのモノラルまたはステレオWAVを対象とします。
ステレオでは信号の強いチャンネルを使用します。

## Webで読み込む

1. 自分のROMを選び、BASICを起動します。
2. コマンド入力待ちになったら、一時停止します。
3. プログラム欄でWAVまたはJ8Aを選びます。
4. 「読み込む」または「読み込んで実行する」を押します。

種類はファイル内容から自動判定し、読込後に種類、名前、バイト数を表示します。
「読み込む」では、現在選んでいるBASICのプログラム領域へ読み込み、入力待ちに戻ります。
実行を再開して`LIST`で確認するか、`RUN`で実行できます。
「読み込んで実行する」では、そのまま`RUN`へ進みます。
BASICを動作中にして別のプログラムを読み込むことはできません。

読込は元のセッションのコピーで処理し、形式検査や読込が失敗した場合は元の状態を保持します。
対応外のROMや読込失敗は画面に表示します。
読込失敗では、ファイル形式と空きメモリーを確認してください。
行数の多いテキストはROMによる登録に時間がかかるため、完了までお待ちください。
ファイルはブラウザー内で処理し、外部へ送信しません。

## J8Aとして保存する

WebでWAVを直接使う場合、事前変換は不要です。
J8Aを保存して繰り返し利用する場合は、機械語と同じ変換コマンドを使います。

```sh
build/native-release/tools/jr8wav decode-native-program PROGRAM.wav PROGRAM.j8a
build/native-release/tools/jr8objdump PROGRAM.j8a
```

変換器が機械語、BASICテキスト、BASIC内部形式を識別してJ8A v1を作ります。
J8AはBASIC対応を含む現行仕様をバージョン1とします。
形式エラーになるファイルは元のWAVから作り直してください。
SDKで作成した機械語は、新しいツールでビルドし直してください。

実機で確認する場合は、入力例と判定表を含む[実機テスト手順](basic-program-physical-test.md)を使ってください。

## 対応範囲

[対応範囲](compatibility.md)に記載した実機録音12本の検証で、通常SAVE／ASCII SAVEの短いプログラム、複数ブロックになる長いプログラム、カナ・GRAPHの読み込みと実行を確認しました。
各2回の録音から復元した内容も一致しています。
実機のカセット入力の電気的な再現は未確認です。
この読込経路は音声の再生時間を再現せず、検証済みのブロックをROMのLOADへ渡します。

一つのプログラムを保存したWAVを対象とします。
複数ファイルを続けて録音したテープ、MERGE、別の機械語ファイルを必要とするBASICとの一括読込には対応していません。
BASICのSAVEだけには、別領域へ置いた機械語の本体が含まれるとは限りません。
エミュレーター内で編集した内容は、[SAVE／MSAVEによるJ8A・WAV出力](program-save-export.md)で保存できます。
