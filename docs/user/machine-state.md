# エミュレーターの状態を保存する

BASICやゲームを、保存した場面から続けるための機能です。
CPUの実行位置、RAM、LCD、タイマーなどの状態をブラウザー内に保存します。
ROMの内容は保存データに含めません。

## 保存と復元

1. エミュレーターの`Save machine state`を押します。実行中なら一時停止してから保存します。
2. 保存完了の表示を確認してから、ブラウザーを閉じます。
3. 次回、同じブラウザー・同じサイトを開き、保存時と同じROMを読み込んで起動します。
4. `Restore machine state`を押します。保存した画面が一時停止状態で戻ります。
5. 再開ボタンを押して続けます。

ゲーム側に専用の中断機能がなくても使えます。
保存枠はサイトごとに1件で、別のプログラムの状態を保存すると置き換わります。
復元しても保存データは消えません。
異なるROMや壊れた保存データは復元できません。
保存に失敗しても、以前の保存データは維持します。

## 時計は巻き戻さない

RTC（時計）は状態保存から独立しています。
ブラウザー時刻を使う設定が有効なら、復元時の現在時刻に合わせます。
無効なら、復元先のエミュレーターの時計を維持します。
そのため、時計を参照するプログラムでは、保存時から時間が経過した状態で処理が続きます。

## 保存されないもの

ROM、RTC、デバッガーの設定、ブラウザーが既に受け取った音声、BASICのSAVE/MSAVEで生成したファイル一覧は含みません。
SAVE/MSAVEのファイル取得中は状態を保存できないため、完了してから保存してください。
ゲーム専用だった旧保存データの変換には対応していません。

サイトの保存データを削除すると、この保存データも失われます。
エミュレーターの再起動は実行中のRAMを初期化しますが、ブラウザーに保存した状態は残ります。
この機能はブラウザー側の状態保存であり、実機の電池保持やハードリセットを再現するものではありません。
