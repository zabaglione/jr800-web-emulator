# ゲームの検証記録

2026-09-11のタイトル・HUD刷新後に確認した、エミュレーター上の結果です。実機性能・実機のLCD BUSY時間・カセット転送の証明ではありません。

## 今回の確認範囲

- 50作品の独立したタイトル画像と、作品ごとのHUDを再生成・ビルドしました。原寸の全作品と、各書体・配置の拡大表示を目視確認しています。
- 全50本のWASM Releaseキー入力再生が成功しました。同じ入力をNativeで再生し、合計223,066フレームのCPUサイクル・画面ハッシュ・LCD転送数・画面状態を照合しました。
- 所有するJR-HuBASIC 1.0 ROMでも全50本の操作再生が成功しました。WASM Debugでは全50本の起動・最初の操作・メニュー停止・復帰を確認しました。
- 直接起動とBASICのCALL起動、50本×2通りの100ケースでBREAK復帰を確認しました。各ケースで空のBASIC、LCDに表示した計算結果、新規BASICプログラムの実行、日付の保持、再ロードしてプレイ中からの2回目の復帰まで検査しています。
- タイトルとゲーム中3場面、計200場面を実行中のLCDから撮影しました。原寸と4倍の400枚をソースとともに管理しています。

公開候補のNative Releaseは63項目が成功しました。Native Debugでも規則とHUDの検査を通過しています。ローカルChromeで全50本の保存ROM復元・自動起動・タイトル画素・実キーと仮想キー・音声開始・再読み込みを確認しました。ROM未設定、不明ID、整合性検査失敗、通常アクセス時の手動起動も検査し、ROMを送信するHTTP要求がないことを確認しています。

## 描画・操作

再生の各フレームで、LCDの12,288画素を1,536バイトの描画面と比較します。静止したタイトル・盤面・停止メニューではLCDデータ転送が0バイトであることを検査しています。

新しいHUDの単体検査は、通常・縦長・横幅のある数字・小さい数字の4種類の書体、0〜65535の桁変化、反転、古い数字の消去、コントローラー境界、同値の再描画抑止を含みます。HPゲージの尺度・上限・消去、左右に移動したプレイ領域の保護、中央の結果表示とその外側の画素保護も検査しました。

BEAT STEPの矢印とBALANCE DOCKの荷物では、描画座標とLCD転送範囲の両方に画面位置を適用しています。荷物の2ドット高のマスクは、変更されない隣の帯を保ち、無変更なら転送範囲を作りません。壁・足場・荷物は独立して再構築した画面とも比較します。

共通のLCD検査はBUSYを0・1・8回の読み取りで遅延させ、画面端とコントローラー境界を含む部分転送を全画面と比較します。入力はテンキーとWASDを論理方向にまとめてから押下を判定します。短い入力、長押し、別キーによる同方向の重複、SPACEの非リピート、画面切り替え時のキー解放とメニュー停止を既存の検査で確認しています。

## RAMと実行時間

標準RAM内でBASICの作業領域を保持する[配置](visual-design.md)へ整理しました。最大割当は12,847バイト、検証経路での最大スタック使用は12バイトです。別途512バイトのスタックを予約します。数値はすべての操作での上限を保証するものではありません。

Eクロック1,228,800Hzによる換算です。RAMはコード・画像・ゲーム状態・描画面・BASIC復帰領域の合計で、CPU内部の共通作業領域は別です。最大更新はタイトルや画面の切り替えも含みます。

## 対応環境と再現

拡張RAMを無効にした検証は、独自の最小起動コードを使用します。所有ROMの起動は既存のBASIC実験プロファイルを使います。JR-HuBASIC 2.0・実機操作・実際の発音品質は対応確認に含めません。音声のブラウザー検査は再生データの供給までです。

[ゲーム再生](../../games/tools/check.mjs)、[Native再生](../../tests/game_replay_test.cpp)、[規則・HUDの単体検査](../../tests/game_rules_test.cpp)、[ブラウザー検査](../../tests/browser_program_launch_test.cjs)を公開しています。`make test`の出力と測定値は`build/games/`へ保存します。Wiki原稿は`docs/games/wiki/`、画像は`docs/games/screenshots/`で管理します。
