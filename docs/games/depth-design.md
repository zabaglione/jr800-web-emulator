# 奥行きと数字の意匠

50作品を確認し、15作品のタイトルと13作品のゲーム中の素材に奥行きを追加しました。残る作品では、既存の陰影や背景を活用するか、盤面・光路・接触位置の読みやすい平面表現を維持しています。座標系を立体に変換する方式ではなく、1bitの陰影・斜めの辺・重なりによる表現です。

## メモリーと描画

ゲームはLCDへビットマップを直接転送します。独自数字はPCG機能の追加ではなく、既存の描画用フォント領域の差し替えです。23作品で計器風・活字風・丸みのある数字を採用し、通常・縦長・横幅のある数字を同じ原画から事前生成します。小さいラベルとパスワードは共通の読みやすい書体を保ちます。

HUDの数字領域は1作品あたり440バイト、共通の小さい文字236バイト、計676バイトのままです。奥行きのあるゲーム素材も従来と同じ寸法・バイト数で、描画回数、当たり判定、論理マス、フレームバッファー数は増えません。タイトルは一度だけ描画し、パズルでは圧縮画像から展開します。全作品のRAM配置はビルドで検査し、スタック512バイトを別に予約します。

## 確認方法

実行中のLCDから全50作品のタイトルと初期盤面を撮影し、原寸と整数倍で確認します。数字を囲む縁が文字に重なったNUMBER RAILは、7ドット高の文字の外側に縁を移しました。キー入力再生では、毎フレームの描画面とLCDの画素一致を検査します。結果とRAM・サイクル測定値は[検証記録](validation.md)、画像は[ゲーム一覧](README.md)から参照できます。実機での液晶の見え方と応答は未検証です。
