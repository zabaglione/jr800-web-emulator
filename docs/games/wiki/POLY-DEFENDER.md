# POLY DEFENDER

[遊ぶ](https://zabaglione.github.io/jr800-web-emulator/?program=poly-defender) · [ビルド可能なソース](https://github.com/zabaglione/jr800-web-emulator/tree/main/games/poly-defender)

![タイトル画面](https://raw.githubusercontent.com/zabaglione/jr800-web-emulator/main/docs/games/titles/poly-defender.png)

陰影の付いた戦闘機を操り、結晶の峡谷と回転体が浮く炉心区画を突破する横スクロールシューティングです。前進して稼ぐか、後退してかわすかを選び、立体の編隊と大型ボスへ挑みます。操作・攻撃・得点・ポリゴン描画・音はすべてJR-800の機械語で動きます。

## 遊び方

### 操作

| キー | 操作 |
| --- | --- |
| SPACE／RETURN | タイトル・終了画面から開始／再挑戦 |
| テンキー8／2、W／S | 上下へ移動 |
| テンキー4／6、A／D | 後退／前進 |
| SPACE | 連射を止めて蓄積／連射を再開して発射 |
| BREAK | 空のBASICへ戻る |

開始時は自動連射がオンです。移動と射撃の同時押しは不要です。SPACEを押し続けても切替は1回だけです。文字キー側の数字と矢印キーは移動に使いません。

`SC`は4桁の得点、`H`は耐久力、`W`は武器、`S`はシールドです。`/1`〜`/3`がエリア番号で、その右側に現在の区間を示します。ボス戦ではHPと行動表示が出ます。

### 攻めるか、待つか

- **前へ出る**：自機を画面左から72px以上の位置へ進めると、下部の`SCORE X1`が`SCORE X2`に変わります。その位置での撃破・アイテム回収は得点が2倍。近づけば弾が早く届きますが、敵の突進や弾に対応する余裕が減ります。
- **後ろへ下がる**：回避の余裕を取り、敵の狙いを見て通路へ合わせます。敵を見逃しても耐久力は減りません。
- **溜め撃ち**：SPACEで連射を止めると`CHARGING`。約1.8秒で`BURST READY`になり、再度SPACEを押すと太い貫通弾を撃ちます。威力は5、ボスの隙には6。準備中は通常の連射が止まります。
- **通路**：縦長の結晶は壊せません。太い貫通弾も止まるため、隙間に合わせるか、壁が流れていくのを待ちます。無理に前へ出ると壁に触れます。3面の浮遊する八面体も壊せず、弾を遮るため、上か下を回り込みます。

### 武器とシールド

`W`を取ると武器が1段階上がります。レベル1は弾1発、レベル2は最大2発の連射、レベル3は威力2の貫通弾です。大型の敵には1発につき1回だけ命中します。溜め撃ちは武器レベル1から使えます。

`+`は1回分のシールド。被弾を受け止めたら`SHIELD BROKEN`が約2秒表示されます。耐久力と武器は失いません。シールドなしの被弾は耐久力と武器が1段階下がり、武器は最低1です。被弾後は短時間の無敵があるので、安全な位置へ移動しましょう。

アイテムは左へ流れます。近づいて早く取るか、危険な位置のアイテムを見送るかを選べます。通常のドロップはWとシールドが交互で、画面にある間は上書きしません。小型編隊は4機撃破するごとにドロップの機会があります。装備が最大でも回収で得点が増えます。

### 3つのエリア

各エリアは迎撃、地形、編隊、ボス戦の順に進み、上部の区間名もエリアごとに変わります。自機は上下移動で機体を傾け、小型編隊も陰影の付いた三角錐として回転します。

1. **OUTSKIRTS**：狙い撃ち・予告付き突進をかわして強化。大型の八面体を倒すと小さい三角錐2体へ分裂します。交互に高さが違う結晶の隙間を抜け、小型編隊と三角錐の突進ボスに挑みます。
2. **CRYSTAL MAZE**：尖った敵が上下に折り返し、異なる速度で接近します。地形区間`CRYST`では、上下から突き出す4組の結晶の隙間へ進路を合わせます。遠くの輪郭が近づくと太い陰影付きの柱に変わります。5頂点の守護者は予告レーザーと上下移動を使います。`BEAM`と`SWEP`に注意しましょう。
3. **REACTOR CORE**：回転する機械型の敵が狙い撃ちします。地形区間`ROTORS`は開けた空間に壊せない八面体が5個流れ込み、上下に動きます。2面とは逆に、中央の物体を避けて上か下を回り込みます。約40pxの高さを持つ最終ボスは画面外から入り、レーザーと大きな船体の突進を使います。突進は後退してかわし、中央の核を狙いましょう。`ARMR`中には溜め撃ちが有効で、`OPEN`中は通常弾も通ります。

`RUSH`／`SWARM`／`DRONES`は18機が次々に流れ込む区間で、同時に最大6機。上下へ広がり、速度の違う編隊が交差します。

ボス前には警告音と`BOSS APPROACHING`。敵・ボス・編隊は画面の右端から流れ込みます。大型敵は入場中に一段階大きくなり、最終ボスは船体が画面外から現れます。敵弾は狙った位置に向けて進み、発射後の追尾はありません。レーザーは発射前に狙った高さを示し、発射が終わるまでその高さを変えません。

ボスのHPは順に20・24・30。`OPEN`では命中ダメージが1増え、HP9以下では追加射撃と短い攻撃周期に変わります。エリアを抜けると耐久力が1回復し、武器・シールド・得点を持ち越します。最後のボス撃破でクリア、耐久力が0でゲームオーバーです。

基本得点は通常敵・小型敵・分裂後の敵が1、分裂前の親が2、ボスが20、アイテムが2です。前線ではこれが2倍になります。表示上限は9999点です。

### 音と被弾演出

描画を優先してBGMは入れていません。開始・クリア・ゲームオーバーのジングル、発射・命中・爆発・分裂・回収・シールド・被弾・レーザーの音を鳴らします。

被弾時は位置を止めて画面を反転し、X印と`HIT BY BOLT / ENEMY / WALL / LASER`で原因を示します。最後の撃墜は数秒残してからゲームオーバーへ移ります。

Webエミュレーターでは画面をクリックして音声を有効にしてください。

## 確認済み環境

JR-HuBASIC 1.0を使ったWebエミュレーターで確認しています。ゲームは標準16KB RAM内に収まり、拡張RAMなしのNative/WASM再生でも検証しています。ブラウザーのBASIC起動には既存のBASIC実験プロファイルを使用します。2.0は対応未確認です。実機動作・カセット転送・実機のLCD応答と音は未検証です。

BREAKで戻る際には、以前のBASICプログラムと変数が消去されます。必要な内容はゲームを読み込む前に保存してください。途中経過はエミュレーターの汎用状態保存で保存できます。ROMとROM入り状態ファイルは配布しません。
