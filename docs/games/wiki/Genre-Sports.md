# スポーツ・タイミング

[ゲーム一覧へ](https://github.com/zabaglione/jr800-web-emulator/wiki)

角度、反応、間合いとタイミングを競うゲーム。

## 収録ゲーム

このジャンルの作品は制作予定です。

## 制作予定

- **WIND PUTT** — 角度と強さを決め、壁や風のあるコースを回る。
- **RALLY RETURN** — CPUと球を打ち合うパドル対戦。
- **PENALTY ARC** — 方向とタイミングを選んでゴールキーパーをかわす。
- **BEAT STEP** — 4方向の合図をCPUサイクルに合わせて入力する。
- **BALANCE DOCK** — 動く荷物を重ね、重なった幅を保って高く積む。
