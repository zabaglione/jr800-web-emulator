# JR-800 ゲームライブラリー

ひとりでじっくり考える。CPUと読み合う。タイミングを合わせて駆け抜ける。
**51本**のゲームから、気になる画面と遊び方を見つけてください。

**ROMを設定済みなら「プレイ」からすぐに起動できます。** 開いた画面をマウスでクリックし、SPACEで始めてください。初回の準備は[こちら](https://github.com/zabaglione/jr800-web-emulator/wiki/Controls)。

じっくり挑戦したい方には、[40面のパズルチャレンジ](https://github.com/zabaglione/jr800-web-emulator/wiki/Puzzle-Challenges)も。規定手数と追加目標を両立して、最高評価を狙えます。パスワードで続きから遊べます。
