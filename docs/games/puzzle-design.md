# パズルのチャレンジ設計

15作品を各40面、合計600面へ更新しました。新規制作の盤面は `games/<作品ID>/challenges.json`、作成時の独立ソルバーは各作品の `design.py` で管理します。各面には通常クリアと追加目標を達成するクリアの2種類の操作手順を収録します。盤面生成や自動解答は製品のWebホストでは動かしません。

## 規定手数と難易度

1〜10面は導入、11〜20面は応用、21〜30面は難しい配置、31〜40面は上級向けです。箱数、巡回範囲、鏡の数、地雷密度、扉の配置、必要な経路の長さなど、作品に合った条件で段階を付けています。難易度は設計上の区分であり、人間の初見プレイによる難易度調査は行っていません。例えばSLIDE NINEの通常解答手数の中央値は、序盤10面の7.5手から終盤10面の28.5手へ、BOX SHIFTは18手から51.5手へ増えます。手順の長さだけでなく、箱の順序・行き止まり・寄り道の両立なども難易度の要素です。

BOX SHIFT、MIRROR LINK、LAMP GRID、SLIDE NINE、ICE ROUTE、SWITCH MAZE、LOOP TRACE、RICOCHET OPSでは、状態探索から最短の追加目標達成手順を求めています。PEG RESCUEとKNIGHT TOURは、戻しなしで全体を完成させる一定の跳躍数が規定手数です。

PIPE WEAVE、NUMBER RAIL、MINE FIELD、STEP STRIKE、POCKET FACTORYは、追加目標を達成できる確認済み手順を規定手数とします。これらの規定手数が数学的な最短手順であるとは主張しません。MINE FIELDは見えている数字と制約の差分から安全マス・地雷を推理する独立モデルを使い、推測せずに解ける固定盤面を採用します。

## JR-800側の実装

共通のチャレンジ処理は `games/common/puzzle.s` にあります。対象の15作品だけに組み込み、ゲーム規則・手数・回収・評価・パスワードの計算はすべてHD6301プログラム内で行います。ほかの35作品の起動・選択方法は変更していません。

- 有効な行動とUNDOを数え、無効な移動と選択カーソルの移動は数えません。評価は1〜3、未クリアは0で、最高評価だけを保持します。
- 表示手数は9999で止めます。以後も操作できますが、内部の超過フラグにより表示上の同値を利用して高評価を得ることはできません。
- 40面の最高評価は40バイトで保持し、パスワードでは1面2ビットへ詰めます。盤面途中の復元は既存の汎用状態保存で扱います。
- 16文字のアルファベットは1文字4ビットです。面指定は作品ID4ビット・面番号8ビット・CRC8ビットの計20ビットで5文字。全記録はさらに40面×2ビットを加えた100ビットで25文字です。CRCは入力ミス検出用で、認証や改ざん防止の仕組みではありません。
- コードは長さ、文字範囲、作品ID、面番号、検査値をすべて確認してから状態へ反映します。不正な入力で記録の一部だけが変わることはありません。
- タイトルと盤面のデータは短いLZパケットで圧縮します。展開は画面切替・面開始時に1回行い、パケット間でも入力を走査します。1〜127のヘッダーはリテラル、128〜255は後方コピー、0は終端です。後方コピーは既に展開した最大255バイト内を参照し、重なりを許します。
- 作品ごとに4ビットの配管・数字、地雷や工場壁のビット列も使い、標準RAM内に収めています。比較用の第2フレームバッファーは追加していません。
- RICOCHET OPSの循環検出は、48マスに8方向のビットを持たせる48バイトの集合です。同じマスへ異なる方向から入る経路を区別します。
- 印は背景の再描画に重ね、取得・戻しで変わるマスだけキャッシュを無効化します。静止中のLCD転送は発生しません。

## 再生成と検証

通常の `make -C games/<作品ID>` は保存済みの盤面から資産と実行ファイルを生成します。盤面そのものを再生成する場合は、その作品の `design.py` を先に実行します。固定した乱数シードを使用します。

`make -C games/<作品ID> test` は通常クリア・追加目標クリア・評価・戻し・再挑戦・パスワードを実際のキー入力で検証します。途中の状態と光路・出荷などを独立したモデルと照合し、各フレームでLCDの全画素とフレームバッファーを比較します。テンキーとWASDは面ごとに交互に使用します。

実行結果とRAM・スタック・入力走査の測定は[検証記録](validation.md)に記載します。JR-HuBASIC 2.0、実機、カセット転送、実機LCDと音は未検証です。
