# JR8DBGソースデバッグ形式バージョン1

## 用途

JR8DBGは、ソースファイル、シンボル、ソース範囲を、完全に一致する1個のJR8APPへ対応付けます。
ソース本文は格納しません。
標準拡張子は`.j8d`、形式名とマジック識別子は`JR8DBG`です。
整数は符号なしビッグエンディアン、文字列はNULを含まない長さ付きUTF-8です。

## ヘッダー

| フィールド | エンコード |
| --- | --- |
| magic | `JR8DBG`の後ろにゼロ2バイトを付けた8バイト |
| version | `u16` major、`u16` minor。バージョン1.0 |
| flags | `u32`。バージョン1ではゼロ |
| target profile | 長さ付き文字列 |
| application integrity SHA-256 | 対応するJR8APPから複製した32バイト |
| source-file count | `u32` |
| symbol count | `u32` |
| line-mapping count | `u32` |

## ソースファイルレコード

各レコードはパス文字列と、ビルドに使ったソース内容のSHA-256を持ちます。
パスはファイル内で一意です。
デバッガーはダイジェストを使い、リンク時と異なるソース本文を拒否できます。

## シンボルレコード

| フィールド | エンコード |
| --- | --- |
| name | 文字列 |
| binding | `u8`。1はlocal、2はglobal |
| kind | `u8`。1はaddress、2はabsolute |
| value | `u16` |
| reserved | `u16`。ゼロ |
| size | `u32` |
| source-file index | `u32`。対応がない場合は`$FFFFFFFF` |

addressシンボルのサイズがゼロなら、値と一致するアドレスだけを検索対象にします。
サイズが非ゼロなら半開区間`[value, value + size)`を検索対象にします。
absoluteシンボルは式と表示には使えますが、アドレス検索には使いません。
local名はソースファイルが異なれば重複でき、global名は一意でなければなりません。

## 行対応レコード

| フィールド | エンコード |
| --- | --- |
| address | `u16` |
| reserved | `u16`。ゼロ |
| length | `u32` |
| source-file index | `u32` |
| line | 1始まりの`u32` |
| column | `u32` |

対応範囲はアドレス順に正規化し、空、重複、16ビット空間外を禁止します。
アドレス検索は、指定アドレスを含む半開区間のレコードを返します。
