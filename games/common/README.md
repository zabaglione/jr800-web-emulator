# ゲーム共通部品

LCD転送・フォント・入力・BASIC復帰は `sdk/lib` を参照します。このディレクトリーには、公開ゲームの画面構成と操作に共通する処理を置いています。

- `runtime.s` はタイトル、面選択、メニュー、結果画面と入力の解放待ちを管理します。
- `graphics.s` は16×7個の背景タイルと文字を1枚のフレームバッファーへ描き、変更した帯だけをSDKへ渡します。
- `grid.s` は論理マスと表示タイルの対応、方向入力、手数を管理します。必要な作品だけがUNDOや規則の補助部品をリンクします。
- `scene.s` は動く物体用です。移動前の矩形に重なる背景タイルを無効化し、`paint_board` で背景を復元した後に物体を描きます。描画領域は左側の128×56ドットで、上端8ドットと右側の情報欄を保護します。追加のフレームバッファーは使いません。

`scene_rect` はAにX、BにY、`scene_w`・`scene_h`に幅と高さを受け取ります。画面外にはみ出す部分は切り捨てます。`scene_pixel` はAにX、BにYを受け取り、1画素を点灯します。既に点灯している画素は変更として記録しません。物体が重なる場合も、背景を復元してから全物体を描く順番にしてください。
