# 01 文字を表示する

![文字表示の実行結果](preview.svg)

`HELLO JR-800`、`MACHINE CODE`、`192 X 64 DOTS`の3行を表示します。
BREAKキーでBASICへ戻ります（JR-HuBASIC 1.0）。終了時にBASICのプログラムと変数を初期化します。
[共通の起動手順](../README.md)でビルドしたサンプルを読み込むと、この画面で止まります。

## プログラムの仕組み

[main.s](main.s)は、LCDとフレームバッファーを初期化し、3回の`text`呼び出しで文字を配置します。
最後に`present`でLCDへ転送し、`frame_ready`の無限ループで画面を保ちます。

```asm
    LDX #title
    LDD #framebuffer + 192 + 60
    JSR text
```

Xには文字列`title`の先頭アドレスを入れます。
Dには描画先を入れます。
`192 + 60`は、縦8ドット単位の段を1つ下げ、そこから右へ60ドット進める指定です。
したがって、この行の左上は`x=60, y=8`になります。

文字列はASCIIコードを並べた`.byte`で定義し、末尾に`0`を置きます。
たとえばHの文字コードは72です。
`text`はこのコードから5×7ドットの字形を選び、1列の空白を加えて次の文字へ進みます。
文字コードが0なら処理を終えます。

## 動作確認と変更例

```sh
make
make run
make test
```

`make test`は表示の完成を確認し、HとXの字形を検査します。
Xは文字表の先頭から256バイト以上離れているため、字形アドレスの桁上がりも確認できます。
さらに、描画用RAMとLCDの12,288ドットを比較します。

練習では、最初の描画先の`60`を`12`へ変え、文字列が左へ移ることを確認してください。
文字を増やす場合は、1文字6ドットとして右端192ドットを越えないように配置します。
