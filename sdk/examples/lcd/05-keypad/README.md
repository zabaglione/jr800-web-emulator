# 05 テンキーでカーソルを動かす

![カーソルの最初の画面](preview.svg)

中央の8×8ドットのカーソルを、テンキーの`4`で左へ、`6`で右へ動かします。
押している間は移動し、離すと停止します。
[共通の起動手順](../README.md)で`05-keypad.j8a`を読み込んでください。

画面右側のテンキーを使うか、PCのテンキーで操作します。
文字キー側の数字は別のキーです。
`4`と`6`は1個ずつ押してください。
同じ選択アドレスで複数キーを押した場合の電気的な挙動は、エミュレーターでも未確定です。

## プログラムの仕組み

[main.s](main.s)は、描画と待ち時間の後で`$0FFE`を読みます。
JR-800では、キーの状態を特定のメモリーアドレスから読み取ります。
この選択アドレスについて、所有者による実機観測で確認された値を使っています。

| 状態 | 読み取る値 |
| --- | --- |
| 押していない | `$FF` |
| テンキー`4`を押している | `$EF` |
| テンキー`6`を押している | `$BF` |

押すと対応ビットが1から0になる方式を**アクティブロー**と呼びます。
たとえば`$EF = 11101111`ではビット4が0です。

```asm
    LDAA $0FFE
    CMPA #$EF
    BEQ move_left
    CMPA #$BF
    BNE render
```

Aへ読込値を入れ、`4`なら左への処理へ分岐します。
`6`でもなければ座標を変更せずに描画へ戻ります。
`6`だった場合だけ右へ進みます。
横座標の初期値は92、移動量は4ドットで、左端0と右端184ではそれ以上進みません。

押下の瞬間を1回だけ検出する処理ではなく、繰り返し読んだ現在の状態を使います。
このため、長押しすると更新ごとに移動します。
LCD描画は[04の跳ね返るスプライト](../04-bounce/README.md)と同じ方法です。

## 動作確認と変更例

```sh
make
make run
make test
```

`make test`は78画面を使い、初期位置、左端への移動、キー解放、右端への移動、端での停止を検査します。
割り当てていないテンキー`5`を押しても座標が変わらないことを確認します。
テストのキー入力は、エミュレーターのキー状態APIを通してC++のキーボードモデルへ渡します。

練習では、テンキー`5`で中央の92へ戻す処理を追加してください。
この選択アドレスにおける`5`単独の観測値は`$DF`です。
変更後は、左右へ移動してから`5`を押し、中央へ戻ることを確認します。
