# RELIC DIVE 開発・検証資料

遊び方は[README](README.md)を参照してください。

## ビルド

[SDK開発ガイド](../../../../docs/sdk/application-development.md)に従って環境を準備し、リポジトリのルートで実行します。

```sh
cmake --build --preset native-release
cmake --build --preset wasm-release
make -C sdk/examples/lcd/07-relic-dive
```

出力は`build/sdk-lcd/07-relic-dive/07-relic-dive.j8a`です。
ゲーム内の中断識別子は`RD01`です。ブラウザーの状態保存はゲームから独立しています。

## 構成とメモリー

| 領域 | アドレス | 大きさ |
| --- | --- | ---: |
| コード・文字・PCGの配置枠 | `$2800–$47FF` | 8,192バイト |
| ゲーム状態・現在の階・視界 | `$4800–$4DFF` | 1,536バイト |
| フレームバッファー | `$4E00–$53FF` | 1,536バイト |
| スタック予約 | `$5E00–$5FFF` | 512バイト |

配置枠の合計は11,776バイトです。
CPU内RAMの`$0080–$00AD`を一時変数に使用します。
拡張RAMは使用しません。
迷宮は24×16マス、表示は24×6マスで上下だけスクロールします。
1階の記録は768バイトで、地形384、敵32体×8、品物32個×3、余り32です。
敵の実数は最大27体、最初に配置する品物は最大12個です。
空いた記録は破棄した品物に使います。

| ソース | 担当 |
| --- | --- |
| `constants.inc` | RAMアドレスと配列の上限を一元化 |
| `main.s` | 起動、入力、画面の切り替え、中断復帰 |
| `dungeon.s` | 迷宮生成、乱数、配置検索、視界 |
| `turns.s` | 移動、攻撃、敵の能力、空腹、自動歩行 |
| `items.s` | 拾得、使用、装備、破棄、下降 |
| `ui.s` | HUD、持ち物、調べる、PCG描画 |
| `assets.s` | 独自の8×8ドット絵と英語の表示文 |
| `check.mjs` | WASM版JR-800モデルによる実行検査 |

付属アセンブラーにインクルード構文がないため、Makeでこれらを順番に連結してからアセンブルします。
共通のLCD転送・5×7文字表示は、ほかのサンプルと同じ`../common/`をリンクします。
停止中は画面全体を書き直さず、操作に応じて描画とLCD転送を行います。

## 動作確認

```sh
make -C sdk/examples/lcd/07-relic-dive test
```

公開版の基本テストは、タイトル表示、冒険の開始、待機によるターン進行、LCDと表示バッファーの一致をエミュレーターで確認します。
`make run`はタイトル画像、`make debug`はレジスターとシンボルを出力します。
JR-800実機での動作は未確認です。
