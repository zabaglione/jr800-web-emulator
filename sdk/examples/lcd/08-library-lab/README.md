# 08 共通ライブラリ実験室

[省RAM機械語ライブラリ](../../../lib/README.md)のSE、単音メロディー、スプライト、スクロール、キー入力を組み合わせたサンプルです。

| テンキー | 操作 |
| --- | --- |
| 4 / 6 | 8×8の図形と地面を左右へ1ドットずつ動かす |
| 5 | 2音の短いSEを1回再生 |
| 7 | 4音のメロディーを1回再生 |
| BREAK | 既存のJR-HuBASIC 1.0向け終了処理でBASICへ戻る |

PCの文字キー側の数字ではなくテンキーを使います。5/7は押しっぱなしでも再演奏しません。メロディーは約1秒、SEは約0.11秒です。音の再生中は画面更新とキー走査が止まります。これはゲームと並行して鳴るBGMのサンプルではありません。BREAKの確認も再生終了後になります。

```sh
make
make run
make debug
make test
make clean
```

Native SDKとWASMの準備は[サンプル共通ガイド](../README.md)を参照してください。`build/sdk-lcd/08-library-lab/08-library-lab.j8a`を通常のWebエミュレーターで読み込めます。`make run`は最初の画面を`screen.svg`に出力します。`make debug`は`frame_ready`で停止した状態とシンボルを表示します。

`main.s`はモジュールの組み合わせ方の例です。キーイベントは表示と短い待ちの間に保持し、フレーム単位で処理します。図形の移動ではその帯を消して描き直し、地面だけをスクロールします。地面の空いた端は0のままなので、動かし続けると空白になります。新しい地形の補充は実装していません。

ライブラリの作業RAMは合計25バイト、入力状態3バイトです。サンプル固有の位置・待ち回数は2バイト、共通の画面バッファーは1,536バイトです。これとは別にコード・文字・音列、既存のBASIC復帰処理と退避領域、スタックがRAMを使います。正確な配置は生成される`.map`を参照してください。

音用のPort 1設定は単独デモの明示的な値です。実機での他の周辺機能との共用やBASICへの復帰は今回未検証です。連続BGMの制約、音程計算、スクロールの測定値とAPIは[ライブラリ解説](../../../lib/README.md)を参照してください。
